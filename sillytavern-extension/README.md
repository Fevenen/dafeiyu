# 大肥鱼酒馆扩展

配套大肥鱼桌宠桥接层，支持SillyTavern 1.19.0的可见剧情陪聊、行动草稿、单轮和有限连续接管。默认关闭，每次刷新都需要重新开启。

回合控制思路参考 [SillyTavern-AI-Player](https://github.com/Sumo1433/SillyTavern-AI-Player)，本扩展独立实现并接入现有大肥鱼服务。酒馆上下文与事件接口见[官方扩展文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)。

## 使用

1. 更新并启动桌宠后端，酒馆主模型继续连接自己的模型服务（本机KVMem通常为18200，不是现实命令网关18080）。
2. 使用发布仓库的 `scripts/install-tavern.ps1 -PetRoot <桌宠目录> -TavernRoot <酒馆目录>` 安装，刷新酒馆页面。
3. 打开一个角色聊天，点击输入框上方“🐋 大肥鱼陪玩”，选择“开启陪玩”。默认桌宠地址为 `http://127.0.0.1:12393`。
4. 陪玩可以手动点评、提问，也可在角色完整回复后自动点评。点评与剧情消息分开；桌宠在线时可播报。
5. “生成行动草稿”不会写入剧情，可以在独立草稿框修改后提交；“直接代玩一轮”明确授权本轮直接提交。
6. 连续接管可选2至5轮，每次最多5分钟。输入文字、点击“我来”、改剧情或换聊天都会暂停；不会自动重发不确定的提交。
7. “关闭”停止同步新剧情；笔记可以单独清除。关闭面板只收起界面，不等于关闭陪玩。

自动点评关注最新回复里的具体细节、疑点、选择代价或当下反应，通常1至2句，不做剧情简介和作品鉴赏。选游戏、定世界观或没有新发现时可以安静；手动“点评当前剧情”仍会尝试给出建议。模型会参考最近三次点评减少重复，语气和判断仍取决于模型。

点评和问答共用当前桌宠角色的核心人设，包括性格、称呼和说话习惯，切换桌宠角色后跟随更新；不带入QQ等工具规则。玩家行动继续按酒馆玩家Persona生成，两种身份分开。

## 当前范围

- 群聊可用于陪玩，接管先支持单角色聊天。
- 接管通过酒馆接口写入玩家消息，角色回复完整生成后显示，不借用或清空主输入框。
- 单条游戏上下文正文最多8000字、近期正文总计16000字，历史最多40条；超出时使用最近内容并在状态中提示。
- 读取聊天正文和当前玩家公开Persona，不读取角色卡、世界书或模型推理。图片、复杂HTML状态面板需要额外适配。
- 首次笔记及之后每隔数次点评整理剧情；删改已覆盖历史时清除旧笔记重建。笔记仍是模型总结，需要结合原文判断。
- 自动点评有30秒冷却，正常桌宠对话或游戏模型忙时跳过。过期待播点评会被丢弃；正在播放的一句可使用桌宠原有打断功能。
- 页面临时令牌、Origin检查及30秒租约约束游戏接口，连接失效后不自动恢复授权。仅允许配置的本机酒馆地址。

## 数据与回退

笔记在桌宠 `bridge/data/games/sillytavern/`；当前剧情只在活跃租约内供桌宠参考。不要提交运行数据或酒馆个人data目录到GitHub。

安装器只覆盖本扩展目录，原文件备份到桌宠 `bridge/data/backups/tavern-extension-*`。关闭陪玩后可在酒馆扩展管理中禁用本扩展；需要还原扩展版本时复制对应备份文件。它不修改酒馆核心、模型连接、角色卡或聊天内容。

后端还提供独立关闭开关：在桌宠 `bridge/config.json` 设置 `"sillytavern_enabled": false` 并重启相关服务，会同时禁用游戏接口和剧情注入，其他现有功能继续工作。默认允许连接，但陪玩与接管权限仍每次从关闭开始。接管行动只接受普通剧情文字，不执行酒馆宏或斜杠命令。

## 验证

`node --test tests/controller.test.js` 验证控制权、轮数、迟到结果和输入保护；发布仓库 `tests/test_tavern.py` 验证后端权限、版本、记忆和语音隔离。

`tests/real-tavern.cjs` 和 `tests/serve_fixture.py` 在独立端口8123/18424与独立data目录验证实际SillyTavern；设置 `PET_TEST_DIR` 后运行，不能指向个人酒馆data。测试模型和密钥均为虚构，测试不向真实联系人发送消息。
