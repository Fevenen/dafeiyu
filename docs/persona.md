# 人格配置

默认日常回复 1–2 句、20–60 字，最多 80 字；只有用户明确要求详细、完整步骤或完整清单才展开。视觉描述只说重点，动作/表情最多一处。工具结果的收件人、内容、时间、状态与确认要求始终完整保留。已有 DSH 会话可能仍使用旧人设，编辑后应新建会话。

安装器会在桌宠目录旁创建 pet_workspace/AGENTS.md，已有文件不会覆盖。编辑后在 DSH 新建会话加载。

config/AGENTS.example.md 是可公开的人格示例；bridge/dsh_persona.md 是同一模板。工具协议要求真实调用、原样传递确认词，并区分待确认、成功、失败与未知。人格语气不会改变这些执行规则。

从 0.1 升级时，可保留自己的角色设定，将示例中的“工具协议 0.2”替换旧工具规则。旧 confirm_send() 示例应改为 confirm_send(confirmation="确认")，或统一调用 route_command。

酒馆陪玩点评与问答从已连接桌宠当前角色的 `character_config.persona_prompt` 提取核心人设，共用身份、性格、称呼、口癖及说话习惯；切换角色后，下次游戏请求使用新角色。无单一客户端时使用默认角色，无法取得角色时回退到公开DSH人设模板。此处只取人设文本，不读取酒馆角色卡，也不会将整份桌宠配置交给模型。

提取时跳过工具、协议、屏幕和现实操作等章节及相关指令行；游戏模型仍不获得现实工具。场景规则保留简短、具体的陪玩表达，允许偶尔一处动作，嘴硬不等于贬低玩家。行动草稿和接管始终使用酒馆玩家Persona，不加载桌宠核心人设，剧情笔记仍客观记录事实与怀疑。
